# 🏆 Rendu Final : Mon Image Personnalisée

Pour clôturer ce premier jour sur Docker, j'ai créé ma propre image personnalisée !

**Ce que j'ai fait :**

1. Création d'un `Dockerfile` basé sur une image `nginx:alpine` (légère et performante).
2. Remplacement de la page d'accueil par défaut par un fichier `index.html` de mon cru.
3. Build de l'image avec la commande `docker build -t image-de-reve .`
4. Lancement du conteneur sur le port 8080.
